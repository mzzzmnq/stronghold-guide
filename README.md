# 卫戍协议 · 战术终端

面向 sganggs/Stronghold-Protocol 的独立攻略网站。无构建步骤，无运行时框架依赖。

## 预览

在本目录运行 `node serve.mjs`，访问 http://127.0.0.1:4178 。也可直接用浏览器打开 dist/index.html（部分浏览器对本地文件的笔记持久化有限制）。

## 内容维护

- `dist/data.js`：独立攻略内容。更新 `version`、`commit`、盟约机制、核心干员、教学出处和版本提醒。
- `dist/app.js`：搜索、导航、体系详情、收藏、备注及备份。
- `dist/style.css`：战术终端视觉与手机、平板断点。
- `research/`：原始研究和源码审查结果，供以后更新核对。

更新攻略时，先固定游戏提交，再核对 `data/bonds.json`、`data/chess.json` 和对应实现。维护者说明可能滞后于实现；必须核对实际代码。原版视频摘要保留发布日期、来源、读取范围，不能自动视为移植版实测。

笔记与收藏保存在当前浏览器 localStorage；“版本与笔记”提供 JSON 导出与合并导入。没有跨设备自动同步。

## 发布

`dist/` 可托管到静态网站服务。Sites 项目标识保存在 `.openai/hosting.json`，更新时复用，不新建。

游戏名称、角色名称归原权利人；本站是非官方、非商业的学习与攻略整理。界面使用自行绘制的几何图案，不分发游戏素材。
